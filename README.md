## 🚀 Proyek Unggulan

### 1. Arsitektur Bali
**Klasifikasi Arsitektur Bangunan Suci Tradisional Bali**

Aplikasi Android untuk mengidentifikasi dan mengklasifikasikan bangunan suci tradisional Bali menggunakan algoritma SVM dan MobileNetV2. Mendukung implementasi AI secara offline melalui ONNX Runtime dan TensorFlow Lite.

Teknologi: Kotlin, Jetpack Compose, Python, SVM, MobileNetV2, ONNX Runtime, TensorFlow Lite.

### 2. EcoTrace
**Sistem Pemantauan Kepatuhan dan Pengelolaan Limbah**

Platform digital untuk pencatatan, pelacakan, dan pemantauan proses pengelolaan limbah komersial. Dilengkapi digital manifest, monitoring rantai pengelolaan limbah, aplikasi Android, serta integrasi AI untuk identifikasi jenis limbah.

Teknologi: Laravel, PostgreSQL, Next.js, Android, Machine Learning.

### 3. Manajemen Aset
**Aplikasi Pengelolaan Aset Berbasis Web**

Aplikasi untuk mengelola data dan inventaris aset dengan integrasi REST API, autentikasi pengguna, serta dashboard untuk memantau informasi aset.

Teknologi: Laravel, Next.js, TypeScript, MySQL.
